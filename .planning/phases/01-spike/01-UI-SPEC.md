# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | none — 原生 AppKit / Svelte 样式 |
| Preset | not applicable |
| Component library | none |
| Icon library | SF Symbols（仅使用 macOS 原生图标；本阶段只保留工具栏挂载位） |
| Font | macOS system font（SF Pro）；编辑区固定 macOS system monospaced font（SF Mono） |

本阶段的窗口外壳由原生 `NSPanel` 承载，视觉采用 macOS 26 Liquid Glass 方向；Svelte 只提供内容层和最小工具栏挂载位。不得用 CSS 伪装全局窗口，不提前实现边缘触发、标签、文件、设置或完整工具栏。

### Visual Hierarchy

1. **主焦点：Monaco 编辑区** — 占据面板剩余空间，使用高对比背景、清晰插入光标和可见焦点环；首次显示或面板重新聚焦时自动获得键盘焦点。
2. **次级：Liquid Glass 工具栏挂载位** — 仅作为原生外壳的低干扰操作区，使用较低视觉重量和分隔线，不抢夺编辑区焦点。
3. **三级：状态反馈** — 桥接状态、加载和错误提示使用短文本/图标，放在工具栏或编辑区边缘，不覆盖正在编辑的文本。

### Panel Width and Responsive Rules

- 面板高度填充当前显示器可用高度；Phase 1 Spike 使用 320px 最小宽度、35% 默认宽度，最大宽度为 60% 屏幕宽度。
- 视口小于 480px 时，编辑区仍保持至少 280px 内容宽度；隐藏非必要的工具栏标签，仅保留 SF Symbol 和 accessible name，文本不换行。
- 视口达到 480px 后恢复图标与标签并保持 8px/16px 间距；不得通过横向滚动压缩 Monaco 编辑区。
- 工具栏和空态采用流式布局，窄宽时垂直堆叠；编辑器始终 `min-width: 280px`、`min-height: 240px`，窗口缩放不得使其不可输入。

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 图标与文字间距、编辑器内联微间距 |
| sm | 8px | 工具栏挂载位内边距、控件紧凑间距 |
| md | 16px | 面板内容默认内边距、编辑器与外壳间距 |
| lg | 24px | 面板主要区域边距 |
| xl | 32px | 编辑工作区与面板边界的宽松间距 |
| 2xl | 48px | 本阶段不使用，保留给后续工作台区段 |
| 3xl | 64px | 本阶段不使用，保留给后续页面级布局 |

Exceptions: 编辑器和原生窗口边缘不得因装饰性留白缩小可编辑区域；所有可点击控件的最小触控/点击区域为 44px × 44px。

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.4 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.2 |

编辑器文本使用 14px SF Mono、400、1.5；编辑器字号不在本阶段提供用户设置。中英文均使用系统字体 fallback，避免自带字体导致语言切换或渲染差异。

## Color

颜色使用 macOS 动态语义色，随系统浅色/深色自动切换；以下值为浅色基线，深色模式使用对应 semantic dark variant。

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `NSColor.windowBackgroundColor`（浅色约 `#F5F5F7`） | 面板外壳、Liquid Glass 背景和空白区域 |
| Secondary (30%) | `NSColor.controlBackgroundColor`（浅色约 `#FFFFFF`） | 工具栏挂载位、编辑器容器和分隔边界 |
| Accent (10%) | `NSColor.controlAccentColor`（系统 accent） | Monaco 焦点边框、文本选择、高亮插入光标、桥接状态成功标记 |
| Destructive | `NSColor.systemRed` | 仅用于本阶段 Spike 错误提示或退出确认，不用于普通状态 |

Monaco 编辑区必须保持高对比：浅色使用 `#FFFFFF` 背景与 `#1D1D1F` 前景，深色使用 `#1E1E1E` 背景与 `#F5F5F7` 前景；正文对比度至少达到 WCAG AA。Accent reserved for: 编辑器当前焦点/选择、原生面板桥接成功状态和明确的主操作反馈；不得给所有可交互元素统一上色。

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `开始编辑` / `Start Editing`（空工作区聚焦 Monaco） |
| Empty state heading | `准备好临时编辑` / `Ready for quick edits` |
| Empty state body | `在编辑区输入或粘贴文本即可开始。` / `Type or paste text to begin.` |
| Error state | `面板暂时无法显示。请重新启动 Edgedor；若问题持续，请检查 macOS 26 与 Apple Silicon 环境。` / `The panel could not be displayed. Restart Edgedor; if the issue persists, verify macOS 26 on Apple silicon.` |
| Destructive confirmation | 本阶段无用户可执行的破坏性操作；若 Spike 退出需确认，使用 `退出 Edgedor？` / `Quit Edgedor?`，按钮为 `继续留在 Edgedor` / `Keep Edgedor Open` 与 `退出 Edgedor` / `Quit Edgedor`，避免通用 `取消/Cancel`。 |

所有可见文案必须根据 macOS 系统语言在简体中文与英文之间切换；不显示调试术语、路径、标签或文件状态。本阶段不提供标签、文件、设置、恢复和自动保存文案。

## Interaction States

- **Loading:** Monaco 或原生面板桥接初始化期间，编辑区显示居中的 `正在准备编辑器…` / `Preparing editor…`，并保留静态编辑区底色；加载完成后提示自动消失并聚焦编辑器。
- **Disabled:** 桥接未就绪时工具栏挂载位控件不可用，使用 50% 前景透明度、禁止点击和 `aria-disabled="true"`；Monaco 初始化完成前不接受输入。
- **Hover:** 指针悬停在工具栏控件时仅显示系统 secondary fill（不使用 accent），图标/标签保持原色；编辑区不因 hover 改变背景。
- **Pressed/Focus:** 按下工具栏控件时使用系统 pressed overlay；键盘聚焦时显示 2px accent focus ring，且不依赖颜色单独传达状态。Monaco 选区和插入光标使用 accent，高对比度不低于正文要求。
- **Error recovery:** 桥接失败提示提供 `重新启动 Edgedor` / `Restart Edgedor` 文案；错误状态不遮挡 Monaco 内容，恢复成功后回到正常层级。

## Accessibility and Keyboard Contract

- 工具栏容器 accessible name 为 `Edgedor 工具栏` / `Edgedor toolbar`；每个图标按钮必须有动作型 name（例如 `聚焦编辑器` / `Focus editor`），不得仅依赖 tooltip 或图形。
- 空态容器 accessible name 为 `Edgedor 空工作区` / `Edgedor empty workspace`；主 CTA accessible name 与可见文案一致。
- 键盘焦点顺序固定为：工具栏挂载位（从左到右）→ 空态主 CTA（若存在）→ Monaco 编辑区；面板首次显示直接将焦点置于 Monaco，`Tab` 不进入装饰性背景。
- 所有控件支持 `Tab`/`Shift+Tab` 导航、`Enter` 或 `Space` 激活，并显示不依赖颜色的焦点环；编辑区保留 Monaco 原生键盘行为。
- 支持 macOS 动态字体尺寸和系统增加对比度；字号放大时工具栏标签可收缩为图标，编辑区不低于 14px，窄宽规则仍须满足 280px 最小内容宽度。
- 状态变化通过 `aria-live="polite"` 暴露给 VoiceOver；错误使用 `aria-live="assertive"`，且不得频繁播报光标或输入变化。
