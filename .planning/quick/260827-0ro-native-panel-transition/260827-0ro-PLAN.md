# 原生面板跨侧过渡与固定层级修复

## 目标

在严格单实例、单 `NSPanel` 约束下修正两项窗口行为：已显示面板切换到另一侧时先从旧侧滑出，再从新侧屏外滑入，不再横穿整块屏幕；固定面板只阻止自动隐藏，失焦后降到普通窗口层级，重新聚焦或再次呼出时恢复浮动层级。

## 任务

### 任务 1：实现单窗口两段式跨侧动画

**files:** `src-tauri/src/native_panel.rs`

**action:** 在 `NativePanel` 中显式记录当前已显示目标边，并在 `show_at_edge_at` 区分首次显示、同侧重新定位和跨侧切换。面板已显示且目标边改变时，不得从当前 frame 直接插值到另一侧目标 frame；应以现有可见 frame 为起点，使用动画总时长的前半段向旧侧屏外滑出，第一段完成后把同一个 `NSPanel` 放到新目标屏幕对应边的屏外起始 frame，再用后半段滑入目标 frame。复用现有缓动和 60 Hz 定时机制，并为两段串联提供明确的完成回调或等价状态机；防止旧定时器在新触发后继续覆盖 frame，保证连续触发时最终位置由最新目标决定。总耗时必须等于用户配置的 `animation_duration_ms`，不能让两段各自使用完整时长。动画关闭时取消所有过渡，直接设置目标 frame、置前并聚焦。首次显示和同侧显示继续从对应侧屏外滑入，不改变宽度比例、多显示器触发点锁定、`last_target` 恢复及单窗口语义。

**verify:** `<automated>cargo check --manifest-path src-tauri/Cargo.toml && cargo test --manifest-path src-tauri/Cargo.toml</automated>`；在 macOS 实机开启动画后依次从左侧、右侧触发，确认窗口先完全退出旧侧再从新侧进入且不横穿桌面；关闭动画后确认左右触发均直接定位。

**done:** 同一个 `NSPanel` 跨侧切换时完成“旧侧滑出 → 新侧屏外重定位 → 新侧滑入”的两段过渡，配置时长覆盖整个序列，禁用动画时无中间帧，连续触发不会留下竞争动画或错误终点。

### 任务 2：让固定面板失焦降层并在聚焦时恢复

**files:** `src-tauri/src/native_panel.rs`、`src-tauri/src/lib.rs`、`src/lib/tauri/panel.ts`、`src/routes/+page.svelte`

**action:** 扩展现有 `panel_action` 桥接，增加只调整层级而不隐藏窗口的 `lower` 动作：原生层对可见面板调用 `setLevel(NSNormalWindowLevel)`，返回 `visible: true`、`focused: false`；Rust 命令白名单、非 macOS fallback 与 TypeScript `PanelAction` 联合类型保持一致。前端 `window.blur` 时，未固定面板继续执行 `hide`，固定面板改为执行 `lower`；新增配对的 `window.focus` 处理，在面板仍可见时执行 `focus`，由现有原生逻辑恢复 `NSFloatingWindowLevel` 并成为 key window，卸载时移除两个监听器。边缘呼出、显式 `show`/`focus` 以及再次固定当前面板都应恢复浮动层级；取消固定不得立即隐藏，之后的首次失焦或外部点击才按现有规则隐藏。不要把 `setHidesOnDeactivate` 改回 AppKit 自动隐藏，以免破坏跨应用边缘触发和全局点击监控的既有职责。

**verify:** `<automated>git diff --check && npm run check && npm run build && cargo check --manifest-path src-tauri/Cargo.toml && cargo test --manifest-path src-tauri/Cargo.toml</automated>`；在 macOS 实机确认未固定失焦仍滑出隐藏，固定失焦保持可见但不压住其他应用窗口，重新点击或呼出 Edgedor 后恢复浮动层级，取消固定后下一次失焦正常隐藏。

**done:** 固定状态只改变自动隐藏策略，不再等同永久置顶；原生、Rust 命令和 TypeScript 动作契约一致，失焦/聚焦监听成对注册与清理，全部编译、构建和格式检查通过。
