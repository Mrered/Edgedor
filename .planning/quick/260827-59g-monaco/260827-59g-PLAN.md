# 持久化 Monaco model 与撤销历史

## 目标

把 Monaco model 的生命周期从 `EditorSurface` 组件实例中分离，改为每个存活标签拥有一个以 `tab.id` 为键的客户端内存 model。编辑器视图可因标签切换而挂载/卸载，但语言检测、设置、快捷键和 Vim 模式变更必须在现有 editor/model 上动态应用，不得以重建 model 作为配置更新手段。

## 任务

### 任务 1：建立可自检的标签 model registry

**files:** `src/lib/editor/modelRegistry.ts`、`src/lib/editor/modelRegistry.selfcheck.ts`、`src/lib/editor/monacoModel.probe.ts`、`src/lib/editor/monaco.ts`、`package.json`

**action:** 新建独立的 model registry，以 `tabId` 唯一索引 model，并通过注入创建 model、设置语言和应用外部编辑的 adapter 使核心生命周期可用 fake 在 Node 中验证。对外提供明确的获取/创建、同步外部内容与语言、仅保留指定标签 ID、释放指定标签和全量释放 API。首次 `createModel` 可直接使用传入初值和规范化后语言；对任何已有 model 严禁调用 `setValue`，因为它会重置 Monaco undo service。语言变更只调用 `monaco.editor.setModelLanguage`；仅在 `model.getValue() !== externalContent` 时，先 `pushStackElement()` 封闭用户当前 undo 单元，再用覆盖 `model.getFullModelRange()` 的 `pushEditOperations` 或保持同一 undo service 的等价全文 edit 替换内容，最后再 `pushStackElement()` 将外部同步封装为单独可撤销单元；不得因语言、视图或快捷键变更重建 model。`src/lib/editor/monaco.ts` 建立生产 registry 实例，调整 `createEditor` 为接收现有 model 而不在函数内新建 model。fake 自检断言：同 ID 多次获取严格复用同一对象，等值内容不写入，外部差异调用一次编辑 adapter 且从不调用 `setValue`，语言变更不替换对象，不在存活 ID 集合中的 model 只 dispose 一次，全量释放后 registry 为空。另新建浏览器可执行的 `monacoModel.probe.ts`，必须导入真实 `monaco-editor`、在真实 `ITextModel` 上产生至少两个独立用户 edit/undo 单元，执行一次外部全文同步，断言同步期间被 suppression 拦截的 `onDidChangeContent` 回传计数为 0，并通过逐步 `undo()`/`redo()` 证明外部同步前的两步历史仍然存在且顺序正确。用 URL query 或仅开发模式动态导入将该探针接入现有 Vite/WebView，成功明确输出 PASS，断言失败必须 throw/返回非成功结果，不得用 fake 结果替代真实 Monaco 证据。在 `package.json` 增加 `check:editor-models` 脚本运行 fake 生命周期自检；若当前 CLI 无法启动浏览器自动化，将真实 Monaco 探针在计划执行结果中标记为 `human_needed` 并给出唯一的运行入口，不得声称已自动验证。

**verify:** `<automated>npm run check:editor-models && npm run check && npm run build && git diff --check</automated>`；`<human-check human_needed="true">`在 Vite/WebView 中运行真实 Monaco 探针入口，只有看到 PASS，且探针已断言多步 undo/redo 与同步期间回传 0 次，才可通过本任务；如执行器能用现有浏览器工具自动访问入口，则收集该 PASS 作为自动证据并取消 `human_needed`。

**done:** 客户端 registry 可稳定复用每个标签的 model，已有 model 的外部内容同步从不调用 `setValue`，而是作为单独全文 edit 保留旧 undo/redo 历史；真实 Monaco 探针和 fake 生命周期自检均通过，按标签集合回收与全量销毁有可重复证据，`createEditor` 不再隐式拥有 model 生命周期。

### 任务 2：让编辑器视图复用 model 并动态重配置

**files:** `src/lib/editor/monaco.ts`、`src/components/EditorSurface.svelte`、`src/routes/+page.svelte`

**action:** 在 `EditorSurface.svelte` 挂载时按 `tab.id` 从生产 registry 取得 model 并交给 `createEditor`，保留现有 view state 恢复与内容/光标/选区/滚动回传；组件卸载只 dispose Vim 模式、快捷键注册、事件订阅和 editor，严禁 dispose registry 持有的 model。用 Svelte 响应更新将 `fontSize`、`showLineNumbers`、`showMinimap`、`showFolding`、`showGlyphMargin` 传给 `editor.updateOptions`，将语言变化传给 registry/`setModelLanguage`；外部 `tab.content` 与 model 不同时才同步，同步动作的严格时序为：先将组件内 suppression 标记设为 `true`，再执行第一个 `pushStackElement`、全文 `pushEditOperations`、第二个 `pushStackElement`，最后在 `finally` 中恢复 suppression；`onDidChangeModelContent` 在 suppression 为 `true` 时不得调用 `onChange`，正常键入仍立即回传。严禁为方便同步而对已有 model 使用 `setValue`。将方案默认快捷键和自定义覆盖改为可 dispose 的注册集合（优先使用 Monaco 返回 `IDisposable` 的 action 注册，不得继续堆叠无法移除的 `addCommand`），每次 profile/覆盖变更先释放旧集合再注册新集合。Vim 切入时初始化 `monaco-vim` 并只叠加自定义 Monaco 覆盖，切出时 dispose Vim 实例后恢复所选非 Vim 方案，不得污染下一次配置。在 `+page.svelte` 将 `EditorSurface` 的 `{#key}` 缩减为仅 `tab.id`（或移除多余 key，但必须确保标签身份是唯一重建边界）；中央化会话应用路径在每次 session 变更后调用 registry 的存活 ID 回收 API，使关闭、过期、清空工作区及其他删除标签路径自动释放对应 model；恢复出厂若不删除标签则不应误释放存活 model。应用销毁时调用全量释放，并清理已有 window listener/timer。

**verify:** `<automated>npm run check:editor-models && npm run check:shortcuts && npm run check:session && npm run check && npm run build && git diff --check</automated>`；`<human-check>`在同一标签输入至少三步可区分文本，依次切换到其他标签再返回、等待自动语言检测切换语言、改变字号与行号/Minimap/折叠/Glyph Margin、切换 VS Code/Sublime/JetBrains/Vim 并修改自定义快捷键；每一步后均用 `⌘Z`/重做验证原撤销链连续，然后关闭并恢复该标签，确认内容可恢复但已关闭标签不沿用旧 model 撤销历史。

**done:** 标签切换、语言自动/手动更改、字号和编辑器显示设置、快捷键方案/覆盖变更都不再销毁 model 或断开撤销/重做链；每个活跃标签只有一个 model，所有标签移除与应用销毁路径可回收资源，自动检查与人工撤销冒烟均通过。

## 验证

- 自动：`npm run check:editor-models && npm run check:shortcuts && npm run check:session && npm run check && npm run build && git diff --check`。
- 真实 Monaco 证据：运行专用浏览器/WebView 探针，验证两步旧 undo/redo 在外部全文 edit 后仍可完整往返，且 suppression 期间 `onChange` 回传为 0；无自动浏览器时必须标记 `human_needed`。
- 人工：在打包或开发应用中执行标签切换、语言检测/手动语言、视图设置、四套快捷键方案及关闭/恢复后的 `⌘Z`/重做连续性冒烟。

## 成功标准

- 任意存活标签的 model 以 `tab.id` 复用，视图重挂载不会释放它。
- 语言、字号、可见性选项、快捷键方案/覆盖与 Vim 切换全部原地生效，不以重建 model 换取配置更新。
- 正常键入会回传 session，外部内容更新只在差异时以可撤销全文 edit 写入 model，不使用 `setValue`、不丢失旧 undo/redo 历史且不触发循环回传。
- 关闭、过期、清空和应用销毁后无遗留 model，registry 自检证明释放只发生一次。
