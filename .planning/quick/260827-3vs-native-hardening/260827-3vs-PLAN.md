## 信任边界

| 边界 | 处理方式 |
|------|----------|
| AppKit/Tauri 退出事件 → WebView 检查点 | 使用有确认、可失败回滚、有限重投递和最终兜底的纯状态机；RESTART_EXIT_CODE 独立优先放行。 |
| WebView localStorage → 原生退出确认 | 捕获同步存储异常并记录，仍发送退出确认；原生命令失败才允许再次请求。 |
| AppKit 菜单/全局鼠标/边缘监听 → Rust PanelState | 所有来源进入同一动作与状态发布入口，不信任临时 JSON 为真实状态。 |
| 保存的 frame/宽度 → NSScreen 布局 | 仅接受可见、有限数值且命中当前有效显示器的 frame；失效目标按明确主屏右侧规则恢复。 |
| NSTimer completion → NSPanel 最终状态 | generation 只取消旧 timer，终态由共享最新 AnimationTarget 收敛，禁止旧 completion 改写新动作。 |

## 成功标准
