# Quick 260827-31h：扩展为四个可调编辑组 Summary

**实现最多四组的归一化扁平编辑布局，支持可取消的 pointer/键盘分隔条、跨组标签拖放和旧快照确定性修复。**

## Accomplishments

- 纯模型支持活动组后插入、第五组拒绝、视觉相邻合并与只改变相邻两组的缩放。
- 反序列化可迁移旧两组比例，并确定性修复 0 组、5+ 组、遗失标签归属和失效活动引用。
- 工作区提供三条可聚焦分隔条，支持鼠标/触控、方向键、Home/End 和完整 capture 清理。
- 内部标签 drop 仅在私有 MIME 或有效内部状态时接管，普通文件与 URI 拖入继续传递到既有外部文件处理。
