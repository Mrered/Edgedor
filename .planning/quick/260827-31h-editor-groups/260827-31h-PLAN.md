# 扩展为四个可调编辑组

## 目标

在保持单窗口、扁平统一方向布局的前提下，把当前两组编辑区扩展为最多四组，建立可恢复的归一化比例模型，并提供与桌面编辑器一致的鼠标、触控、键盘分隔条及任意组间标签拖放。

## 信任边界

| 边界 | 处理方式 |
|------|----------|
| localStorage 会话 JSON → 内存模型 | 对方向、组数、权重和活动组做结构校验与规范化，旧格式只按明确迁移规则读取。 |
| HTML DragEvent dataTransfer → 标签移动 | 使用私有 MIME，验证 tabId 确实属于当前会话，阻止内部 drop 冒泡到外部文件处理。 |
| Pointer/键盘输入 → 布局比例 | 所有数值进入纯模型后检查有限值、相邻索引和最小比例；cancel/lost capture 使用统一清理，不让页面直接写状态数组。 |

## 成功标准

- `npm run check:session` 自动证明四组上限、比例不变量、两种相邻删除活动语义，以及 0 组、5+ 组、失效活动引用与新旧会话恢复。
- 工作区可显示四个横排或竖排编辑组，全部相邻边界均可用 pointer 和键盘调节。
- 布局方向、比例和活动组不会因普通拖动立即写盘，但在下一次既有合法 checkpoint 后可跨重启恢复。
- 任意类型标签可在任意组间拖动；取消/完成内部拖动都会清理状态，不影响随后的外部文件拖入。
- `npm run check`、`npm run build` 与 `git diff --check` 全部通过。

## 人工冒烟

1. 连续创建到四组，再点一次分区，确认只提示达到上限且四组内容和比例不变。
2. 在横排、竖排两种方向下拖动每条分隔条至两端，确认相邻组不越过最小宽度/高度，非相邻组不跳动；拖动中触发 pointercancel 或让控件丢失 capture，确认调整立即停止且下一次拖动正常。
3. 仅用键盘操作三条分隔条，确认方向键、Home、End 与 aria 数值变化一致。
4. 将临时、真实文件、图片/PDF 预览标签依次拖入不同组和空组，确认目标激活、内容不变且没有触发打开文件提示；取消一次标签拖动后立即拖入外部文本/PDF，确认外部文件仍由既有打开流程处理。
5. 设置不等比例和活动组后先执行合法 checkpoint，再重启，确认四组顺序、比例、方向、标签归属和活动组完整恢复。
