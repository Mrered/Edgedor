# 修复最终前端审查的数据安全缺陷

## 目标

关闭外部文件拖放、损坏恢复数据、关闭恢复启动顺序、异步保存竞态、快捷键验证漂移和内部拖放状态泄漏六类缺陷；不改变现有文件格式支持、单次 `⌘S` 写回语义或会话检查点边界，也不新增依赖。

## 信任边界

| 边界 | 处理方式 |
|------|----------|
| Finder/AppKit → Tauri WebView | 只信任 Tauri 原生 `drop.paths`，路径继续进入现有 Rust 文件大小、解码和预览边界；不信任 WebKit `File.path`。 |
| localStorage JSON → SessionState | 所有字段从 unknown 逐项验证并重建 plain object；损坏或空快照删除后安全回退。 |
| 设置恢复开关 → 会话内容读取 | preserve=false 在任何 SESSION_KEY 读取前删除并短路，避免已禁用恢复的数据再次进入内存。 |
| 异步保存对话框/IPC → 可变 UI 状态 | 保存请求在入口捕获，返回结果只按稳定 tabId 归并，已关闭标签不复活。 |
| 用户快捷键文本 → Monaco 命令注册 | UI 与注册器共享解析器，拒绝裸键、重复修饰键、未知键和未知命令。 |
| HTML5 DataTransfer → 编辑组状态 | 只接受私有 MIME，残留进程内 draggedTabId 不能授权外部 drop。 |

## 成功标准

- `npm run check:session` 覆盖损坏/恶意快照、无恢复读取短路和保存竞态。
- `npm run check:shortcuts` 证明裸键拒绝且合法组合键解析一致。
- Finder 多文件使用 `getCurrentWebview().onDragDropEvent` 的 `drop.paths`，源码不再依赖 HTML5 `File.path`。
- HTML5 拖放仅在私有 MIME 存在时阻止默认行为和移动内部标签，所有退出路径清理拖动状态。
- `saveActive` 异步期间切换、编辑或关闭标签都不会覆盖其他标签、误清 dirty 或复活已关闭标签。
- `npm run check`、`npm run build` 和 `git diff --check` 全部通过。

## 人工冒烟

1. 关闭“重启后保留暂存区数据”，预置旧 SESSION_KEY 后重启，确认打开空工作区且旧内容未出现；再启用恢复，用开发者工具注入损坏字段/空快照，确认安全回退并清理。
2. 从 Finder 一次拖入文本、图片和 PDF，确认分别打开；随后跨编辑组拖动标签、取消拖动、切换应用再拖外部文件，确认无旧标签误移动。
3. 在设置中尝试 `D`、`Delete`、`F2` 和合法 `Cmd+D`，确认前三者拒绝、后者生效且重启后仍可注册。
4. 临时标签保存时切换标签，绑定文件保存时继续输入，并在另一次保存期间关闭目标标签；确认保存目标、dirty 状态和标签生命周期都符合任务 3 行为。
