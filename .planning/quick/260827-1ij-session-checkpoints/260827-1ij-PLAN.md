# 严格限定会话内容检查点

## 目标

把 Edgedor 的内存状态更新、独立设置保存和会话内容快照彻底分离，确保 `edgedor.session` 只在用户规定的生命周期边界写入；同时让所有正常退出路径在原生进程结束前完成同一检查点，并用最小 Node 自检锁定“关闭恢复绝不写内容”的隐私约束。

- **范围排除：** 不改变真实文件 `⌘S` 写回语义，不新增自动测试框架，不处理异常崩溃时尚未到达检查点的最新字符。

## 成功标准

- `edgedor.session` 的所有写入集中在 `writeSessionCheckpoint`，页面只有 `checkpoint` 能调用它。
- 恢复关闭时，设置变更立即删除旧快照，后续标签切换、隐藏和退出也只删除不写入。
- 设置、重命名、过期、启动和重水合路径通过代码结构与 storage 操作日志自检证明不会写 session。
- 顶部标签、搜索结果、编辑组焦点等真实激活切换以及面板隐藏会保存最后状态。
- Cmd+Q 和原生菜单栏退出均完成 checkpoint 后正常退出，所有自动检查通过。
- Updater 的 relaunch 在 checkpoint 后仍走 Tauri 重启码，Rust 状态机单测证明重启不会被普通退出拦截。

## 人工冒烟

1. 启用恢复，编辑临时标签后按 Cmd+Q；重新启动 Edgedor，确认退出前最后内容与激活标签恢复。
2. 再次编辑后从菜单栏选择“退出 Edgedor”；重新启动，确认同样恢复，且退出过程没有卡住或连续弹出请求。
3. 在可用更新的已安装版本中执行“检查更新”并确认安装；确认应用自动重新启动而不是只退出，重启后恢复更新前的最后内容与激活标签。
4. 关闭恢复后分别执行 Cmd+Q、菜单栏退出和更新重启；确认应用可正常退出/重启，且下次启动不会恢复此前编辑内容。
