# Quick 260827-19k：Vim 自定义快捷键覆盖即时生效摘要

## Accomplishments

- 提取 `applyShortcutOverrides`，Vim 分支不再遍历 `shortcutProfiles.vim` 中的 `g*`、`dd`、`gcc` 等序列。
- VS Code、Sublime Text 和 JetBrains 仍保持方案默认键，同命令的用户覆盖会替代默认绑定。
- 新增已知命令排序指纹和 `check:shortcuts`，验证键顺序稳定、修改/删除可感知且 Vim 默认序列不被篡改。
