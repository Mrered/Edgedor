# Vim 自定义快捷键覆盖即时生效

## 目标

让 Vim 键位方案在保留 `monaco-vim` 模态编辑行为的同时，接受图形设置中八项 Monaco 编辑命令的自定义快捷键覆盖；四套方案修改或清除覆盖后均立即替换当前编辑器实例，且 Vim 不把 `g*`、`dd`、`gcc` 等 Vim 序列误注册为 Monaco 单次组合键。

## 任务

### 任务 1：分离方案注册与纯覆盖注册

**files:** `src/lib/editor/monaco.ts`、`src/components/EditorSurface.svelte`

**action:** 在 `src/lib/editor/monaco.ts` 提取并导出只遍历 `shortcutOverrides` 的 `applyShortcutOverrides`，仅为 `commandIds` 中已知命令且能由 `parseKeybinding` 解析的覆盖值调用 `editor.addCommand`；复用一个内部命令注册助手，避免方案默认值与覆盖逻辑重复。保留 `applyShortcutProfile` 对 VS Code、Sublime、JetBrains 的既有语义：每个方案命令使用覆盖值替代对应默认值，未覆盖命令继续注册方案默认值。在 `EditorSurface.svelte` 中，非 Vim 继续调用 `applyShortcutProfile`；Vim 必须先 `initVimMode`，随后只调用 `applyShortcutOverrides`，不得遍历或加载 `shortcutProfiles.vim` 中的 `g*`、`:%s`、`ddP`、`ddp`、`dd`、`gcc` 序列。组件销毁时继续释放 Vim 模式、编辑器订阅、编辑器和模型，避免快捷键方案切换后残留旧实例。

**verify:** `<automated>npm run check && npm run build</automated>`；检查 Vim 分支只引用 `applyShortcutOverrides`，非 Vim 分支仍引用 `applyShortcutProfile`，并确认 `applyShortcutOverrides` 不读取 `shortcutProfiles.vim`。

**done:** Vim 模态行为由 `monaco-vim` 独占，图形设置中的有效覆盖可额外触发对应 Monaco 编辑命令；其他三套方案保持默认快捷键并以同命令覆盖值替代默认绑定，类型检查和前端构建通过。

### 任务 2：用稳定覆盖指纹驱动即时重建并增加自检

**files:** `src/lib/shortcuts.ts`、`src/lib/shortcuts.selfcheck.ts`、`src/routes/+page.svelte`、`package.json`

**action:** 在 `src/lib/shortcuts.ts` 增加确定性的覆盖指纹函数：只纳入已知 `EditorCommand`，按命令 ID 排序后序列化绑定，使对象插入顺序不同但内容相同得到同一结果，而新增、修改或删除任一覆盖都会改变结果。在 `src/routes/+page.svelte` 的 `EditorSurface` `{#key}` 中同时纳入 `shortcutProfile` 和该稳定覆盖指纹；不得直接依赖对象引用或未排序的 `JSON.stringify`。设置输入沿用现有 `setShortcutOverride` 校验、冲突检测与清除逻辑，状态持久化后由 key 变化销毁旧编辑器并创建新实例，确保四套方案都不会保留被修改或清除的旧 `addCommand`。新增 `src/lib/shortcuts.selfcheck.ts`，断言覆盖指纹与键顺序无关、修改绑定会变化、删除覆盖会变化，并验证 Vim 的自定义覆盖仍可通过 `resolveShortcut` 解析而不改变 Vim 默认序列表；在 `package.json` 增加 `check:shortcuts` 脚本，以现有 Node TypeScript 自检方式运行。

**verify:** `<automated>npm run check:shortcuts && npm run check && npm run build && git diff --check</automated>`；人工冒烟依次在 VS Code、Sublime、JetBrains、Vim 中修改一个覆盖并触发，再清空该覆盖，确认无需关闭设置或重启应用即可生效，且 Vim 的普通模式命令仍正常。

**done:** 四套快捷键方案的覆盖新增、修改和清除都会立即重建编辑器并移除旧绑定；稳定指纹不会因对象键顺序造成无意义重建；Vim 原生序列与图形自定义 Monaco 组合键同时可用，全部自动检查通过。
